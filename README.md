# Уловка Привратника

Игра для двух команд и ведущего. Одно постоянное поле, три фигурки, три персональных выхода. Подготовлена для телефонов и планшетов; внутри команд можно совещаться, между командами — без речи.

## Три планшета

1. На планшете ведущего открыть сайт, выбрать «Ведущий / разработчик», затем «Создать общую партию».
2. На первом командном планшете выбрать «Подключиться» и ввести код партии. Привратник случайно назначит команду.
3. На втором командном планшете так же ввести код. Ему достанется другая команда. Название и роль раскрываются только после входа.
4. Партия хранится на сервере 24 часа; страницу ведущего можно закрыть. Нужен обычный интернет, устройства могут находиться в разных сетях. WebRTC и настройка сети не требуются. При потере связи ходы приостанавливаются; есть повторное подключение.

Для проверки в одиночку выбрать «Ведущий / разработчик»: обе схемы расположены рядом. «Полная схема» показывает триггеры и опасности на поле Искр. «Ход решения» воспроизводит следующий шаг проверенного кратчайшего решения, если положение соответствует этому маршруту.

## Управление

Пальцем перетащить знак в соседнюю точку по желобу. Отпустить и нажать «Подтвердить ход». Это одно общее решение команды, не серия перемещений. Можно отменить ещё не подтверждённый ход. На компьютере работает мышь; при фокусе на фигурке можно выбрать направление стрелками и подтвердить кнопкой.

У каждого знака свой цвет и выход: Солнце — жёлтый, Луна — голубой, Молния — фиолетовый. Чужой выход занимает отдельный конечный приёмник; заходить в него нельзя. Завершившая путь фигурка остаётся у собственного выхода.

Фигурки не проходят друг сквозь друга. Перегородки скрыты, поднимаются между точками при приближении фигурки к триггеру и исчезают, когда точка освобождается. Опасный участок возвращает все фигурки на старт. Урон ведущий учитывает сам. Карта и триггеры никогда не рандомизируются.

## Проверка сложности

test.mjs перебирает все безопасные достижимые состояния, проверяет наличие решения, отсутствие безопасных безвыходных положений и невозможность вывести фигурки строго по одной до конца в любом из шести порядков.

Результат версии 0.2: 10 693 состояния, кратчайшее решение 31 ход, безвыходных безопасных состояний нет. Для завершения придётся перемещать ещё не выведенные фигурки, освобождая путь другим.

Это не доказывает, что игрокам будет трудно или что они не угадают верный маршрут с первого раза. Обсуждение, запоминание скрытых перегородок и реальный темп требуют живого прогона.

## Разработка

Статический сайт находится в корне репозитория и публикуется через GitHub Pages. index.html — меню и интерфейс, app.mjs — управление и связь, engine.mjs — правила, level.mjs — неизменное поле, solution.json — проверенный маршрут для режима разработчика. Для локальной проверки достаточно любого статического HTTP-сервера.

Сеть: HTTPS API https://gatekeeper-game-relay.devilxrom.chatgpt.site и серверное хранилище партий. Сервер проверяет роль, ревизию и допустимость каждого хода. Тени получают только свою сводку, без координат фигурок и перегородок. Изменения передаются периодическим опросом, без прямого соединения устройств. Ключ ведущего и ключи команд различаются. Код партии действует сутки.

Подключение: видимые этапы и крутилка; общий предел 30 секунд, после которого попытка останавливается и доступна кнопка повтора. Параллельные поиски не запускаются. При обрыве ответа ход не отправляется повторно автоматически.

Смена ролей на главном экране доступна всем: это интерфейс настольной игры с доверенными игроками, а не защищённая соревновательная система.

Файлы PeerJS в vendor/ оставлены для старой версии, но больше не загружаются и не используются. Шрифты: Manrope и Prata, Google Fonts, с системными запасными шрифтами.


## Версия 0.4

Команды: Искры (подвижные жетоны) и Тени (карта опасностей). Первое назначение случайное, следующие балансируются; повторный вход с того же планшета/вкладки сохраняет роль. Координат на поле, в уведомлениях, подтверждениях и доступных подписях нет. Внутренние идентификаторы узлов остаются в исходном коде для проверок.

Подвижные жетоны приподняты над камнем, имеют ободок и тень. Гнёзда утоплены и не выглядят кнопками. Попытка взять гнездо вызывает короткую подсказку Привратника. Победа описывается как открывание двери. Игровые реплики — от лица Привратника; технические ошибки сохраняют ясное объяснение.

Дополнительные действия Теней ещё не добавлены — это отдельный следующий этап.


## Версия 0.5 — зачарованная доска

Атмосферный слой вынесен в atmosphere.css: каменная фактура и фаски, туман, светящаяся пыль, парящие жетоны с отдельными тенями. Огоньки ловушек используют собственный восьмикадровый SVG-спрайт flame-sprites.svg. make-sprites.mjs воспроизводит его без внешних зависимостей. Режим уменьшенного движения отключает постоянную анимацию и фоновые частицы.

Легенда под полем убрана. У каждого знака своя сцена прибытия. При финальном ходе сначала показывается прибытие последнего знака, затем открывание двери. Пять ловушек имеют отдельные эффекты и по три реплики Привратника; повторное попадание меняет реплику и рисунок эффекта.

Сервер сохраняет очередь важных событий (без координат для Теней), чтобы при задержке опроса не терялись уведомления. На новом входе прошедшие сцены не повторяются. Механика поля и его решение не изменены.
